# HostShell 架构设计

## 1. 进程模型

```
┌──────────────── 主进程 (Node) ────────────────┐        ┌──────── 渲染进程 (React) ────────┐
│ store      配置/连接持久化、safeStorage 加解密   │  IPC   │ App / TabBar / TerminalView      │
│ session    ssh2 客户端、shell 通道、SFTP、Zmodem │◀──────▶│ Sidebar / BottomPanel / 各弹窗    │
│ monitor    /proc 采集与差分                      │        │ zustand store                    │
│ ping       本机 ICMP (ping.exe)                  │        │ xterm.js / CodeMirror            │
│ proxy      HTTP CONNECT / SOCKS5                 │        └──────────────────────────────────┘
│ rdp        生成 .rdp 调 mstsc                     │
│ hostinspect tracert + 逐跳 ping                  │
│ ipc        统一注册所有 channel                   │
└──────────────────────────────────────────────────┘
```

- 渲染进程通过 `contextBridge` 暴露的 `window.api` 访问主进程，`nodeIntegration` 关闭。
- 终端字节流只走一条通道：主进程 `session:data` → 渲染进程按 `clientId` 分发到对应 xterm 实例。
- 渲染进程自己生成标签 UUID 作为 `clientId`，主进程沿用为 `sessionId`，避免「首个提示符早于会话注册」的竞态。

## 2. 数据模型

```
%APPDATA%/HostShell/data/
  config.json                 窗口、主题、字体、背景图、代理、命令库、开关
  conn/<id>_connect_config.json   一条连接一个文件（含分组，is_group=true）
```

连接字段（节选）：

| 字段 | 说明 |
|---|---|
| `host` / `port` / `user_name` | 连接目标 |
| `password` | `enc:` 系统加密 / `plain:` 明文（仅 Mock 演示）/ `legacy:` 不可解密的外部密文 |
| `conection_type` | 100 = SSH，200 = RDP |
| `parent_id` | 所属分组，`root` 为顶层 |
| `proxy_id` | 关联 `config.proxies[]`，`0` 为直连 |
| `port_forwarding_list` | 端口转发规则 |
| `custom_size` / `width` / `height` / `fullscreen` / `drivestoredirect` | RDP 参数 |

## 3. 关键模块

### 3.1 会话（session.ts）

- `connect()`：可选经代理建立 socket，再交给 ssh2；密码经 `safeStorage` 解密。
- `openShell()`：终端通道按 **Buffer** 处理（Zmodem 需要按字节识别），普通文本用 `StringDecoder` 解码后上抛。
- `exec()`：一次性命令通道，供监控/进程/系统信息使用。
- SFTP：`readdir` / `realpath` / `stat` / `mkdir` / `rename` / `remove` / `chmod` / 读写文件 / 上传下载。
- 打包传输：远端 `tar czf` → SFTP 取回 → 本地解压；上传反之，带进度事件。

### 3.2 监控（monitor.ts）

单次 `exec` 组合采集，主进程做差分，避免频繁往返：

```
cat /proc/stat      → CPU 使用率（两次采样差分）
free -k             → 内存/交换
df -kP              → 磁盘
ps -eo ... --sort   → 进程表（内存/CPU/命令三种排序）
/proc/net/dev       → 每网卡上下行（差分）
/proc/uptime        → 运行时长与负载
```

刷新节奏：指标 2s，进程表随指标一起刷新；Ping 独立 2s。

### 3.3 SFTP 与终端联动

解析提示符尾部路径（`#`、`$`、`>` 之后的部分），归一化后驱动文件面板切换目录；
用户手动在文件面板导航时暂停跟随，直到下次终端换目录。

### 3.4 代理（proxy.ts）

`connectViaProxy()` 建立到目标的 TCP：HTTP 用 `CONNECT`，SOCKS5 走握手/可选认证/域名 CONNECT；
握手完成后把多读的字节 `unshift` 回 socket，再交给 ssh2。

### 3.5 Zmodem（zmodem.js Sentry）

```
SSH Buffer → StringDecoder + Sentry.consume()
   ├─ 普通输出 → 终端
   ├─ 检测到 **\x18B → 接收会话：offer.accept() → 落盘
   └─ rz 场景 → 发送会话：选文件 → 8KB 分片 send() → end()
```

- 文件落盘到 `config.download_path`，未配置时用系统下载目录下的 `HostShell`，重名自动加序号。
- **看门狗**：落盘后 2.5s 内没收到结束帧就重建 Sentry，避免会话卡死导致后续传输全部失败。

### 3.6 RDP（rdp.ts）

生成 UTF-16LE + BOM 的 `.rdp`（分辨率/全屏/磁盘重定向/剪贴板），`spawn('mstsc.exe', [file])`。
密码不落盘，由系统凭据弹窗输入。

### 3.7 桌面集成

- 托盘菜单：显示主窗口 / 连接管理器 / 开机启动 / 退出
- `close_to_tray` 开启时关闭只隐藏窗口，会话保持
- `requestSingleInstanceLock()` 单实例
- 窗口位置与大小持久化

## 4. 渲染层

- `state/store.ts`：zustand，持有 tabs / activeId / split / metrics / pings / cwd / toast / 各类弹窗状态。
- `TerminalView`：xterm + fit/search/web-links/unicode11；主题来自 `lib/themes.ts`（124 套 JSON），背景图叠加模糊与不透明度。
- 分屏：两个 `.term-host` 按百分比定位，分隔条拖动改比例，点哪栏哪栏为当前会话。
- 命令栏：历史（上下键）、前缀补全、远端路径候选、快捷命令模板。

## 4.1 国际化

- 语言包集中在 `src/renderer/src/i18n/index.ts`，键名形如 `settings.general` / `conn.new`。
- 基准语言为英文（键最全），其余语言缺失的键回落到英文，再回落到键名本身。
- 内置 9 种语言：zh-CN、en、ja、ko、de、fr、es、ru、pt-BR；`normalizeLocale()` 做宽松匹配（zh-TW → zh-CN，pt → pt-BR）。
- 首次启动跟随系统语言（`navigator.language`），选择结果保存在 `config.locale`，`''` 表示跟随系统。
- 切换语言即时生效：`useT()` 订阅 `config.locale`，组件自动重渲染。
- 当前覆盖范围：欢迎页、状态栏、侧栏、命令栏、标签栏提示、底部面板页签、设置页与连接管理器主界面；文件表格表头与部分对话框仍为中文，后续按同一机制补全。

## 5. 视觉规范

| 项 | 值 |
|---|---|
| 主色 | `#0d9488`（青绿），辅助 `#2dd4bf` |
| 背景 | 应用 `#edf6f4`，卡片 `#ffffff`，分隔线 `#d8ebe7` |
| 文本 | 主 `#12302c`，次 `#3d5c57`，弱 `#5d7b76` |
| 圆角 | 控件 7px，卡片 10px，标签 8px |
| 导航栏 | 48px 图标栏（品牌 + 连接 / 监控 / 文件 / 命令 / 设置） |
| 侧栏 | 160px，白底指标卡，指标条主色渐变 |
| 终端 | 卡片式：8px 外边距、10px 圆角、1px 边框、轻阴影 |
| 命令栏 | 固定浅色工具条（`#f6f8fa`），按钮深色文字，不随终端配色变化 |
| 标签栏 | 40px，药丸形标签，激活态白底 + 主色下划线 |
| 状态栏 | 26px，深墨绿 `#0e2f2b`，显示「开源 · MIT」 |

### 5.1 模块扩展位

左侧图标栏是后续模块的统一入口，新增模块只需：

1. 在 `App.tsx` 的 `nav.rail` 里加一个按钮 + 图标；
2. 在 store 增加对应的面板状态（参考 `sidebarOpen` / `bottomView`）；
3. 面板本身作为独立组件挂到主区域。

预留方向：Redis / SQL 连接管理与查询编辑器、AI 助手（终端命令解释、日志分析）。

## 6. 打包

| 产物 | 方式 |
|---|---|
| `win-unpacked` | `electron-builder --dir` |
| ZIP 绿色版 | `electron-builder --win zip`（`compression: maximum`） |
| 安装包 | `build/installer.nsi` + NSIS 3.04，LZMA solid |

瘦身要点：renderer 依赖放 `devDependencies`（已被 Vite 打包），生产依赖只留 `ssh2` 与 `zmodem.js`；
`electronLanguages` 仅中英；asar 18.8 MB → 3.0 MB，ZIP 110 MB → 97 MB。
