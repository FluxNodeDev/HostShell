# HostShell

[中文](../README.md) · [English](../README.en.md) · [日本語](README.ja.md) · [한국어](README.ko.md) · [Deutsch](README.de.md) · [Français](README.fr.md) · [Español](README.es.md) · **Русский** · [Português](README.pt-BR.md)

Универсальная рабочая среда для серверов: терминал SSH, SFTP, мониторинг в реальном времени, туннели и Zmodem — в одном окне.

> Открытый исходный код (MIT), локальный подход. Интерфейс использует левую панель иконок и терминал в виде карточки,
> поэтому управление Redis / SQL и ИИ-помощник можно будет добавить в то же окно.

![HostShell](../shots/app-final.png)

## Возможности

- **Подключения**: дерево групп, перетаскивание, множественный выбор, массовое открытие/удаление, импорт из JSON
- **Терминал**: вкладки, разделённый вид, широковещательный ввод, поиск, 124 цветовые схемы, фоновое изображение
- **SFTP**: панель следует за каталогом терминала, загрузка/скачивание, drag & drop, групповые операции, передача tar.gz
- **Мониторинг**: CPU / память / swap / нагрузка, таблица процессов, сеть, диски, ping
- **Инструменты**: менеджер процессов, диагностика хоста (traceroute), информация о системе, перенаправление портов, ping из нескольких точек, Zmodem
- **Команды**: история, автодополнение, подсказки путей, быстрые команды с параметрами
- **Подключение**: SSH (пароль/ключ), удалённый рабочий стол Windows, прокси HTTP CONNECT / SOCKS5
- **Рабочий стол**: трей, сворачивание в трей, автозапуск, один экземпляр
- **Языки**: Русский / English / 简体中文 / 日本語 / 한국어 / Deutsch / Français / Español / Português (BR)

## Быстрый старт

```powershell
npm install
npm run dev        # разработка
npm run build      # сборка в out/
npm start          # предпросмотр сборки
```

Node 18+; Windows / macOS / Linux.

### Сборка дистрибутива

```powershell
npm run dist:dir     # портативная папка → release/win-unpacked/HostShell.exe
npm run dist:setup   # установщик → release/HostShell-<version>-setup.exe
```

| Артефакт | Описание |
|---|---|
| `release/win-unpacked/` | Портативная версия (232 МБ) |
| `release/HostShell-0.17.0-win.zip` | Портативный ZIP (97,3 МБ) |
| `release/HostShell-0.17.0-setup.exe` | Установщик (71,7 МБ) |
