# HostShell 推广文案与发布清单

> 基于「如何在 GitHub 上获得 1000 star」一文的经验整理：README 是门面、演示决定转化、
> 社区推广要软（技术内容夹带项目地址）、issue 要认真维护。本文件是可复用的发布素材。

## 一、发布前检查清单

- [ ] README 顶部有徽章：Release、License、CI、平台、下载量
- [ ] README 第一屏能看懂「这是什么、解决什么问题、怎么装」
- [ ] 三平台安装包 + 直链在 Release 里
- [ ] 仓库 About 填了 Description 和 Topics
- [ ] 有截图（最好有 GIF/视频）
- [ ] Issues 模板、Discussions 已开启
- [ ] LICENSE、CONTRIBUTING、ROADMAP 就位
- [ ] 有一个「一句话卖点」：*一个窗口做完 SSH、SFTP、监控、隧道*

## 二、一句话 / 短文案

- 中文：**HostShell —— 开源的服务器工作台：SSH、SFTP、实时监控、隧道、Zmodem，一个窗口全搞定。免登录、免云同步，配置只在本机。**
- English: **HostShell — an open-source server workbench: SSH, SFTP, live metrics, tunnels and Zmodem in one window. Local-first, no account, no cloud.**
- 更短的：**把 Xshell + WinSCP + 简易监控，合成一个 97 MB 的开源客户端。**

## 三、LINUX DO（首选，氛围友好）

标题建议：

- `[开源] HostShell：SSH + SFTP + 实时监控 + Zmodem，一个窗口的服务器工作台`
- `写了个开源的 FinalShell 替代品，支持三平台和 9 种语言`

正文要点：

1. 痛点：SSH 一个窗口、SFTP 一个窗口、监控再开一个，切来切去
2. 做法：终端和文件面板同屏，`cd` 自动跟随；左侧实时指标来自 `/proc`，不用装 agent
3. 亮点：Zmodem 双向、隧道、多地点 Ping、9 种语言、暗色/124 套配色
4. 技术栈：Electron + React + xterm.js + ssh2
5. 安装包直链（Windows exe / macOS dmg / Linux AppImage）
6. 求反馈：你最想要 Redis/SQL 还是 AI 助手？
7. 结尾放仓库地址

## 七、节奏建议

- 第 1 周：LINUX DO 发一帖 + 知乎发一篇技术文
- 第 2 周：V2EX 发一帖（准备好被质疑）
- 之后：每发一个版本，在各社区的回帖里更新一次（不要重复开新帖）
- 每条 issue 24 小时内回应；bug 修完在 issue 里说明原因并 close
- 有 PR 时：review 后合并，并在 README 的 Contributors 里致谢
